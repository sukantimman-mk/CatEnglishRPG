ภารกิจประจำวันนี้ (Daily Quests)

♾️ ทำไมระบบนี้ถึงเป็น Endless Loop?

ระบบจะสุ่มภารกิจใหม่ทุกเที่ยงคืน มีการคิดคะแนนและจัดสถิติการเล่นซ้ำเพื่อให้คุณจำวลีภาษาอังกฤษได้แบบซึมซับ (Spaced Repetition). คุณสามารถกลับมาฝึกด่านเดิมซ้ำเพื่อเพิ่มความคล่องตัว และเก็บเงินซื้อไอเทมระดับตำนานในร้านค้าได้ไม่สิ้นสุด

🔊 ระบบเสียง & การพูด

เสียงเอฟเฟกต์ & เสียงแมว (Sound FX)
เสียงดนตรี 8-bit เสียงเหรียญ และเสียงครางเหมียวๆ
เสียงอ่านของ NPC (Text-To-Speech)
อ่านออกเสียงประโยคภาษาอังกฤษอัตโนมัติ

ℹ️ ระบบใช้ Web Speech API ของเบราว์เซอร์ ซึ่งทำงานได้ทันทีโดยไม่ต้องเชื่อมต่อ Cloud API เสียค่าใช้จ่าย

💾 บันทึกและสำรองข้อมูลเซฟ

ข้อมูลเลเวล ไอเทม และความคืบหน้าจะถูกเซฟอัตโนมัติในเบราว์เซอร์ (LocalStorage). คุณสามารถส่งออกไฟล์เซฟเพื่อย้ายเครื่องเล่นได้
